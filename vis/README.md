# Visualisation

## Reader examples

Start with the three small Spain 2030 notebooks in [`demos/`](demos/README.md).
They follow one projected heatwave day from weather to grid inputs and a
single-hour OPF solve. Their supporting data and the solver input bundle are
included in the repository. The project website displays the same selected
grid snapshot interactively, without running the solver.

## Publication figures

The [`figure_source/`](figure_source/README.md) directory contains the plotting
scripts and bundled data for reproducing the paper's figures. Its README
provides the data-to-figure commands and environment instructions.
